설치와 첫 연결

  1. 설치 파일을 받아 실행합니다. 설치가 끝나면 고래등 POS가 바로 열립니다.
  2. 서버 없이 먼저 둘러보기: 첫 화면 맨 아래 '서버 없이 체험해 보기'를 누르면 시험용 매장이 바로 열립니다. 점주 PIN 1234, 직원 PIN 1111. 가짜 QR 주문·직원 호출·포장 주문이 저절로 들어오고, 결제는 실제로 나가지 않습니다.
  3. 실제 매장에서는 첫 화면에 서버 주소(예: https://pos.매장도메인)와 점주 계정을 넣고 로그인합니다. 이 PC가 매장 기기로 등록됩니다.
  4. 직원 PIN 화면에서 점주 PIN으로 들어갑니다. 처음 PIN(0000)은 반드시 새 PIN으로 바꾸게 되어 있습니다.
  5. 설정 → 카드 단말기에서 'KIS 단말기'를 고르고 연결 확인을 누릅니다. "연결됨 · TID …"가 보이면 됩니다. (KIS 에이전트를 먼저 설치해야 합니다.)
  6. 설정 → 프린터 / 주방 출력 경로에서 프린터를 확인하고 테스트 출력합니다. 주방 출력을 맡을 PC 한 대만 '주방출력 담당'을 켭니다.
  7. 손님 휴대폰으로 테이블 QR을 찍어 주문해 보세요. 홀 화면에 바로 새 주문이 뜹니다.
